What It Does

一个助手，管好一个平台的运营全局。

聚焦家装零售垂直平台，覆盖从选品决策到日常运营的完整链条。

01

选品与市场调研

先看清楚，再决定做不做
  • 潜力品挖掘：扫描趋势与需求信号，过滤竞争过热的红海品类
  • 单品 Go / No-Go 裁决：流量、竞争、毛利、风险全链路评估
  • 品类市场调研：市场规模、竞争格局、价格带分布一次出报告
  • 用户评论之声：差评高频问题聚合，痛点直接转化为选品标准
02

Listing 与内容优化

让每一件商品都讲得清楚
  • 标题与关键词优化：对齐平台搜索规则与买家真实搜索词
  • 五点描述重构：卖点排序、参数取舍、场景化表达
  • 图文结构诊断：按转化逻辑逐屏检查详情内容
  • 合规自检：上架前扫描敏感词、错类目与政策雷区
03

广告与促销运营

花在刀刃上，效果可衡量
  • 广告投放拆解：结构、关键词、出价逐项诊断，给出推进路线
  • 促销策划：按季节、节点与库存状况生成促销方案
  • 利润测算：到手价、物流、佣金、退货全成本利润模型
  • 写操作一律过人工审批门，批准后才会执行
04

数据速览与盯盘

日常经营状态，随时一句话问到
  • 价格速查：给品类词或链接，一次抓出现价、划线价、折扣幅度
  • 库存速览：库存健康度与断货风险提示
  • 容量测算：类目容量与增长空间估算，输出置信区间
  • 趋势速览：类目热度走向与季节性判断
