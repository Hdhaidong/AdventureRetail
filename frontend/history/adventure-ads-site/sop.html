① 冷启动期

目标快速增加曝光和点击
核心指标
  • 曝光
  • 点击
  • 点击率 CTR
检验重点
  • 初期流量获取是否通畅
  • 产品是否具备初步市场接受度

② 起量爬坡期

目标放大曝光、积累可持续转化、拉升产品排名
核心指标
  • 曝光、点击率提升
  • 转化率爬升
  • 部分核心关键词排名上升
检验重点
  • 曝光/CTR/CVR 是否稳步上升
  • 核心关键词排名是否上升

③ 稳定跑量期

目标跑稳定流量、控成本、持续放量
核心指标
  • ROAS 达到健康区间
  • CPC 趋于稳定
  • CVR 维持健康水平
  • 广告带动总销量稳定上升
检验重点
  • ROAS 是否具备持续性
  • 广告拉动销量是否稳定
  • 整体推广成本占比是否健康

④ 冲量爆发期

目标高强度收割 + 活动爆发，结合活动/节点快速冲刺销量
核心指标
  • 曝光、点击短期内大幅提升
  • CPC 合理波动不失控
  • ROAS 可短期承压但转化不明显下滑
  • 广告带动总销量显著爆发
检验重点
  • 短期高强度投放的爆发力
  • 转化稳定性

投放前自查 · 关键词筛选

  • 相关关键词报告（后台 Analytics → Search Insight）拉词，按词性/流量/相关性分类：词根 / 核心词 / 人群词 / 特性词 / 颜色词 / 功能词
  • 先确认商品类目正确（Shelf path 类目属性 / Search catalog performance）
  • 文案达标：标题 ≤150 字符、详描 ≥150 词含品牌、五点 ≤80 字符突出卖点；listing 质量分 90+
  • Search query reports 自查关键词与 item 匹配度；Search catalog performance 看类目排名与小类目周度曲线
